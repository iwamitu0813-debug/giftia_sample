## 班の開発ルール

| 項目 | 内容 |
|---|---|
| ブランチ命名規則 | `feature/やること` の形式で作成する（例：`feature/search-form`） |
| mainブランチ | mainには直接pushせず、必ずPull Request（PR）を作成する |
| PRのレビュー | PR作成者以外のメンバー1名が内容を確認し、Approve（承認）する |
| Merge担当者 | PRを承認したメンバーがMergeする |
| 情報共有 | 分からないことや困ったことは遠慮なく班で共有する |
| Slackでの連絡 | PRを作成したとき、MergeしたときはSlackで知らせる |
| .envの管理 | `.env` などの秘密情報はGitHubにアップロードしない |

## AIの使い方

AIを利用した開発では、`AGENTS.md` に記載されたルールに従う。
